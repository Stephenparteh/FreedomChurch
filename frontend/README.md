# NFPC V2 — Frontend

React + TypeScript + Vite + Tailwind CSS v4 + React Router. See the root [`README.md`](../README.md) and [`docs/`](../docs/) for the full project context, architecture, and design system.

## Develop

```bash
npm install
npm run dev       # http://localhost:5173
```

## Build & verify

```bash
npm run build      # tsc -b && vite build
npm run lint        # oxlint
npm run preview     # serve the production build locally
```
